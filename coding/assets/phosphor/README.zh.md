# Phosphor 图标

[English](README.md) | 中文

来自 [Phosphor core](https://github.com/phosphor-icons/core) 的 Regular 图标，npm 包版本为 `@phosphor-icons/core@2.1.1`，采用 [MIT 许可证](LICENSE)。原始路径为 `assets/regular/<name>.svg`；`icons.svg` 的 symbol 保留原始几何路径。

界面需要这些图标时，将 `icons.svg` 和 `LICENSE` 复制到项目本地资源目录。使用真实 SVG 标记，并为所属操作提供无障碍名称；装饰图标使用 `aria-hidden="true"`。示例：`<svg viewBox="0 0 256 256" aria-hidden="true"><use href="assets/phosphor/icons.svg#magnifying-glass"></use></svg>`。

Symbol：squares-four, list-checks, users-three, magnifying-glass, caret-down, arrow-up-right, x, funnel, warning-circle, check-circle, clock, play, dots-three, arrows-down-up。
