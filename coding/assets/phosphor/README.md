# Phosphor icons

English | [中文](README.zh.md)

Regular icons from [Phosphor core](https://github.com/phosphor-icons/core), npm package `@phosphor-icons/core@2.1.1`, under the [MIT license](LICENSE). Original paths: `assets/regular/<name>.svg`; the geometry is preserved in `icons.svg` symbols.

Copy `icons.svg` and `LICENSE` into a project's local assets when its interface calls for these icons. Use real SVG markup with an accessible name on the owning action; decorative icons use `aria-hidden="true"`. Example: `<svg viewBox="0 0 256 256" aria-hidden="true"><use href="assets/phosphor/icons.svg#magnifying-glass"></use></svg>`.

Symbols: squares-four, list-checks, users-three, magnifying-glass, caret-down, arrow-up-right, x, funnel, warning-circle, check-circle, clock, play, dots-three, arrows-down-up.
