# Jev patterns in CodeCrew

The linked [AI Labs video](https://www.youtube.com/watch?v=2nc_QMuNp18), available through its [published-caption mirror](https://prepublish.ai/youtube-transcript/2nc_QMuNp18), describes seven uses: compaction, requirement/test checks, skill selection, file ranking, review triage, browser choices and project-rule checks. Its full implementation is offered through the creator's community; these integrations are independently implemented.

Public source inspected includes [disler's file tools](https://github.com/disler/ten-levels-of-jev/blob/main/apps/ten-levels/extensions/ask-jev-file.ts), [compaction extension](https://github.com/disler/ten-levels-of-jev/blob/main/apps/ten-levels/extensions/jev-compact.ts), and [bravegeek's Claude adapter](https://github.com/bravegeek/jev-claude/blob/main/mcp/server.ts). Their reusable pattern is a narrow typed decision around existing tools, with code applying policy. No project code or dependencies were copied into CodeCrew.

TypeSafe's [primitive definitions](https://github.com/typesafe-docs/typesafeai/blob/main/docs/04-primitives/README.md) and [confidence formulas](https://github.com/typesafe-docs/typesafeai/blob/main/docs/05-confidence.md) inform the native Choice, Noul and Score implementation. Choice answers must name a maximal-probability approved option; scores must agree with the probability-weighted rubric; Noul confidence is derived from distance from uncertainty. A reported confidence cannot exceed the computed distribution statistic. These checks detect malformed answers, not whether Jev's judgment is correct.

CodeCrew keeps local skill rules first, asks Jev only for eligible misses, and preserves explicit worker model choices. Automatic decisions and explicit advice share the existing request budget. Mechanical lookups and exact copy/spacing edits skip automatic requests. Local lexical shortlisting can miss a semantically relevant skill; manual loading remains available. Worker routing uses configured role names and model descriptions, not live price lookup or a claim that Jev measures model competence.

The extended `coding_decide` tool can answer typed questions over explicitly selected files, with canonical workspace containment, unchanged-version checks, sensitive-file refusal and complete input-byte limits. It returns answers, file identities and ranking probabilities, without adding source text to the coding model's context. Source text is transmitted to the configured decision provider. Normal reads remain necessary for editing or quoting, and internal assessment reads never authorize edits. Recognizable-secret filters are not a general data-loss-prevention system.

The [owning tool reference](../packages/experimental/tool-agent-team/README.md#automatic-routing-and-bounded-evidence) documents all recipes and limits. Review triage stays conservative; browser, rule and compaction recipes are advisory. They execute no clicks, block no edits, accept no task and remove no history. Existing permissions, native compaction, workspace memory, tests and supervisor verification remain authoritative. No new decision call runs after every tool or every turn.

Validation covers the real provider and agent loop: explicit model overrides, routing fallback, skill invocation restrictions, shared budgets, conservative review, single-request file ranking, source-text exclusion, canonical symlink containment, stale reads, unknown-size streams and complete Unicode/JSON byte limits. The model settings suite is also exercised. These are correctness and integration checks; no general latency, cost or coding benchmark improvement is claimed.

Live checks used the existing Luna chat route and OpenRouter Jev: two-file ranking selected the access-control source in 611 ms; a mixed Noul/Score request completed in 504 ms, correctly retaining uncertainty for a marginal yes/no result. An unmatched Better Auth task automatically loaded a permitted skill that fit the instruction budget. These are individual integration measurements, not overall speedups. Skill bodies above the configured budget remain omitted whole. Repeated requests for an unchanged automatically loaded skill now return a compact reminder instead of duplicating instructions.
