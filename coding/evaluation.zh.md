# 编码评估

[English](evaluation.md) | 中文

本地评估通过实际 CodeCrew 桌面 Host 和已配置模型账户执行，使用隔离、无外部依赖的 JavaScript 示例仓库。评估对象是借鉴 [Super-agent](https://github.com/deepseek-ai/dsh-superagent-prototype) 的分派实现，不是 DeepSeek 原型或其基准结果。

## 任务与结果

小任务修复时长格式中的秒数补零，保留不受小时限制的分钟数。Luna 在 13.76 秒内完成，调用五次工具，没有 worker 或工具错误。原有测试及十项独立边界断言通过。

大任务实现带验证的 JSON 任务解析器、保序并发映射器及 runner 整合。Worktree worker 独立提交模块，主管审查和整合提交、补充测试，再凭持久证据验收。两次运行的 worker 执行区间均有重叠。

| 观察项 | 初次运行 | 最终运行 |
| --- | ---: | ---: |
| 耗时 | 196.44 秒 | 122.05 秒 |
| 主管工具调用 | 64 | 32 |
| 主管工具错误 | 6 | 0 |
| Agent 编写的仓库测试通过数 | 10 | 20 |
| 独立补充测试通过数 | 15 | 15 |
| 全部 agent 报告的总 token | 2,019,020 | 1,218,024 |
| 全部 agent 缓存读取 token | 1,898,368 | 1,075,072 |
| 全部 agent 报告的未缓存输入 token | 109,529 | 135,336 |
| 全部 agent 输出 token | 11,123 | 7,616 |

初次运行由 Luna 主管协调两名 Sol worker。最终配置在分派时将 Lead 切换到获准 planner profile（Astra）；解析器使用 Sol，映射器使用 Luna。整合后 Lead 返回 Luna，全局默认仍为 Luna。首次启动还发现 worktree 服务未挂载，已在统计这两次完成运行之前修正。分派状态增加当前任务版本，以减少无谓的验收重试。

## 代码质量与限制

独立检查覆盖无效配置、重复及未去除空白的 ID、非有限数值、映射器参数验证、不可变输入、输出顺序、并发上限、首次失败后停止接收新任务、等待已启动调用结束、保留假值拒绝原因，以及 runner 在调用 handler 前验证配置。最终代码全部通过。源码审查发现模块简短、沿用项目约定且未添加依赖；并发映射器使用独立失败标记，避免将假值拒绝误判为成功。

这只是一组任务，模型路由不同，模型及缓存变化未受控制。报告的总 token 包含缓存输入，不能证明费用降低：未缓存输入增加，模型价格也不同。结果证明路由可用及定向检查通过，不代表普遍提速、可直接用于生产或稳定达到高级工程师水准。实际仓库仍需自身测试、类型检查、整合审查及相关 UI 验证。Worker 报告仍是主管需要验证的陈述。

## 协调器继续执行复测

11 月 3 日，通过原生应用复测相同的无依赖编码示例，包含目标检查点、整批并发启动、后台任务继续执行和紧凑技能发现。精确 UI 文案修改由 Luna 在 7.38 秒完成，四次工具调用，没有 worker、自动技能或工具错误。独立比较确认只改变指定按钮文字。格式化函数复测耗时 14.07 秒，八次工具调用，原有测试与十项独立断言通过。

首次协调器 runner 复测耗时 142.54 秒，Lead 调用 44 次工具、发生四次工具错误；15 项仓库测试和 15 项独立测试全部通过。此次暴露任务格式修复开销。下表最终复测使用更明确的 Markdown 标题说明，并停止把 worker 报告视为新技能任务。两次观察均保留。

最终两次错误为任务名称查找和遗漏初始目标，均未启动未经授权的分配。Sol 解析器与 Luna 映射器 worker 在独立工作树中有重叠执行，Astra 监督集成验收。独立测试再次覆盖无效配置、顺序、并发上限、排空和假值异常。模块保持小型、无依赖。最终运行 token 较少但耗时较长；模型、缓存及生成测试差异不支持普遍速度或计费结论。格式化函数与首次协调器运行同独立 UI 评估末段重叠；最终协调器与精确文案修改同时启动。

## UI 质量评估

新建纯 HTML/CSS/JavaScript 示例提供八条演示任务和本地 CodeCrew 标志。两版接收相同简报：派生统计、搜索、状态筛选、优先级排序、空结果、键盘可访问详情面板、无依赖或网络素材，以及 390px/1440px 布局。评估者没有编辑生成的实现。

基线要求不必要的设计确认并停滞。明确要求继续后，又耗时 287.00 秒完成；包含确认等待的总时间为 837.31 秒。独立浏览器检查在要求的移动视口复现 701px 文档宽度。其结束回复也承认溢出和对比度问题未解决。

新版 UI 路由本地选择设计技能，Sol 构建、委派后由 Astra 监督，Sol worker 实现交互。无需确认，耗时 472.54 秒。GUI 浏览器启动失败后，改用独立无头 Chromium。验证时修复了对话框 Tab 焦点和文字对比度。独立检查通过搜索、空结果、blocked 筛选、升序排序、打开任务、带名称关闭按钮、Escape、焦点恢复与单控件对话框 Tab 限定。390px 下文档宽 375px，没有可见控件越界；1440px 下宽 1425px。最终桌面概览的有界计算样式检查未发现可见纯色文字对比度告警，不等于完整可访问性审计。

| 观察项 | 基线 | 新版 UI 运行 |
| --- | ---: | ---: |
| Lead 工具调用 | 75 | 51 |
| Lead 工具结果错误 | 11 | 1 |
| 初始技能目录条目 | 109 | 4 |
| 初始目录 UTF-8 字节 | 13,589 | 973 |
| 全部 agent 报告总 token | 4,530,179 | 1,865,362 |
| 全部 agent 缓存读取 token | 4,397,952 | 1,655,296 |
| 全部 agent 报告未缓存输入 token | 101,919 | 180,570 |
| 全部 agent 输出 token | 30,308 | 29,496 |

子进程验证失败与工具结果错误分别计算。新版生成的响应式功能更完整，工具结果错误更少，但比基线确认后的执行更慢，且以更强模型消耗更多未缓存输入。包含缓存的总 token 较少不证明成本较低。此运行中 worker 反馈还触发无关审查技能；最终源码仅将用户或已记录父级输入视为技能任务，并有回归覆盖。此边界修复经最终编码复测验证，没有再次完整生成仪表盘。

另以相同 109 项合成目录测量真实技能插件：完整模式为 13,589 字节，四项模式为 1,004 字节，该块减少 92.6%。此值不包含可选搜索工具 schema，衡量字节而非提供方 token、延迟或计费。
