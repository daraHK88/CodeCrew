# 编码评估

[English](evaluation.md) | 中文

本地评估通过实际 CodeCrew 桌面 Host 和已配置模型账户执行，使用隔离、无外部依赖的 JavaScript 示例仓库。评估对象是借鉴 [Super-agent](https://github.com/deepseek-ai/dsh-superagent-prototype) 的分派实现，不是 DeepSeek 原型或其基准结果。

## 任务与结果

小任务修复时长格式中的秒数补零，保留不受小时限制的分钟数。Luna 在 13.76 秒内完成，调用五次工具，没有 worker 或工具错误。原有测试及十项独立边界断言通过。

大任务实现带验证的 JSON 任务解析器、保序并发映射器及 runner 整合。Worktree worker 独立提交模块，主管审查和整合提交、补充测试，再凭持久证据验收。两次运行的 worker 执行区间均有重叠。

| 耗时 | 196.44 秒 | 122.05 秒 |
| 主管工具调用 | 64 | 32 |

初次运行由 Luna 主管协调两名 Sol worker。最终配置在分派时将 Lead 切换到获准 planner profile（Astra）；解析器使用 Sol，映射器使用 Luna。整合后 Lead 返回 Luna，全局默认仍为 Luna。首次启动还发现 worktree 服务未挂载，已在统计这两次完成运行之前修正。分派状态增加当前任务版本，以减少无谓的验收重试。

## 代码质量与限制

独立检查覆盖无效配置、重复及未去除空白的 ID、非有限数值、映射器参数验证、不可变输入、输出顺序、并发上限、首次失败后停止接收新任务、等待已启动调用结束、保留假值拒绝原因，以及 runner 在调用 handler 前验证配置。最终代码全部通过。源码审查发现模块简短、沿用项目约定且未添加依赖；并发映射器使用独立失败标记，避免将假值拒绝误判为成功。

这只是一组任务，模型路由不同，模型及缓存变化未受控制。报告的总 token 包含缓存输入，不能证明费用降低：未缓存输入增加，模型价格也不同。结果证明路由可用及定向检查通过，不代表普遍提速、可直接用于生产或稳定达到高级工程师水准。实际仓库仍需自身测试、类型检查、整合审查及相关 UI 验证。Worker 报告仍是主管需要验证的陈述。

## UI 质量评估

新建纯 HTML/CSS/JavaScript 示例提供八条演示任务和本地 CodeCrew 标志。两版接收相同简报：派生统计、搜索、状态筛选、优先级排序、空结果、键盘可访问详情面板、无依赖或网络素材，以及 390px/1440px 布局。评估者没有编辑生成的实现。

基线要求不必要的设计确认并停滞。明确要求继续后，又耗时 287.00 秒完成；包含确认等待的总时间为 837.31 秒。独立浏览器检查在要求的移动视口复现 701px 文档宽度。其结束回复也承认溢出和对比度问题未解决。

新版 UI 路由本地选择设计技能，Sol 构建、委派后由 Astra 监督，Sol worker 实现交互。无需确认，耗时 472.54 秒。GUI 浏览器启动失败后，改用独立无头 Chromium。验证时修复了对话框 Tab 焦点和文字对比度。独立检查通过搜索、空结果、blocked 筛选、升序排序、打开任务、带名称关闭按钮、Escape、焦点恢复与单控件对话框 Tab 限定。390px 下文档宽 375px，没有可见控件越界；1440px 下宽 1425px。最终桌面概览的有界计算样式检查未发现可见纯色文字对比度告警，不等于完整可访问性审计。

子进程验证失败与工具结果错误分别计算。新版生成的响应式功能更完整，工具结果错误更少，但比基线确认后的执行更慢，且以更强模型消耗更多未缓存输入。包含缓存的总 token 较少不证明成本较低。此运行中 worker 反馈还触发无关审查技能；最终源码仅将用户或已记录父级输入视为技能任务，并有回归覆盖。此边界修复经最终编码复测验证，没有再次完整生成仪表盘。

另以相同 109 项合成目录测量真实技能插件：完整模式为 13,589 字节，四项模式为 1,004 字节，该块减少 92.6%。此值不包含可选搜索工具 schema，衡量字节而非提供方 token、延迟或计费。

## 并行执行回归检查

除非 `select_supervisor` 显式请求改变阶段，分派会保留 Lead 模型。新的 worker 会话使用各自独立的模型路由，不复制主管对话。基于 barrier 的测试让一个主管和三个专长 worker 的模型请求同时保持执行。另一测试确认已停止且 blocked 的 CSS 任务释放执行容量，使无关 JavaScript 继续运行，同时仍阻止冲突 CSS 写入。隐式切换 Lead 与停止 worker 占用容量这两个用例都在修复前行为上失败，修复后通过。三个未指定模型的分派现在在既有请求预算内共享一次决策建议请求。

这些是使用模拟模型 adapter 的确定性运行时测试，不代表实测真实模型提速或成本下降。相关测试命令为 `bun run vitest run packages/experimental/agent-team/tests/team.spec.ts packages/experimental/tool-agent-team/tests/tool-team.spec.ts`。下方受控重跑使用相同初始文件和任务；上文既有测量仍是历史证据。

## 工作成员上下文与 UI 标准

后续 dashboard 重跑保持六个初始文件和任务提示完全一致。成员现在接收按角色划分的规则和工具，不接收主管检查点或自动加载整个界面的设计工作流。完整任务描述仍可显式读取。编码配置提供带许可证的本地 Phosphor sprite、简短 UI 清单和可复用浏览器检查器。

| 观察 | 之前并行运行 | 诊断候选 | 最终首次运行 | 最终含修复 |
| --- | ---: | ---: | ---: | ---: |
| 活跃耗时 | 406.23s | 710.03s | 438.26s | 522.51s |
| 全体 agent 总 token | 3,191,609 | 5,158,227 | 1,966,764 | 2,942,774 |
| 未缓存输入 | 138,810 | 208,851 | 100,937 | 116,755 |
| 输出 | 28,287 | 33,792 | 21,859 | 23,075 |

尽管成员规则更短，诊断候选仍更慢且消耗更多 token。重建后其渲染页面失效，但 Host 继续运行；未记录到轮次间隔。最终候选将成员工具模式从 47 项降为 23 项，模式字节从 41,866 降为 16,555，系统消息字节从 13,664 降为 6,758。简报包含参考路径和相关视觉标准。CSS 与 JavaScript 成员并行执行。Lead 在实现前创建并检查移动端和桌面参考，复用浏览器助手，并使用原始 Phosphor sprite。

独立检查在首次运行后发现页面滚动条外观仍可见。另一次 52.67 秒的样式修复将其隐藏，同时保留滚动；要求 `--hide-scrollbars` 时，检查器现在会拒绝该缺陷。另一次 31.57 秒的修正修复了四个低对比度计数标签，并标记装饰分隔符；共享检查器现在提供可强制要求的有界纯色文本对比度检查。滚动条修复还暴露了另一问题：详细的机械修改请求触发了不必要的完整设计技能。回归检查确认旧路由失败，并验证有界修复不会请求建议模型或加载完整设计指令。最后这项路由修正有确定性覆盖，没有新的真实延迟测量。

包括两次修复后，相比之前并行运行，总 token 减少 8%、未缓存输入减少 16%、输出减少 18%；活跃耗时增加 29%。仅首次运行的总 token 减少 38%。两者均不能证明计费下降或提速。评估者检查间隔不计入活跃耗时。交互、焦点约束、Escape/关闭/焦点返回以及响应式布局均进行了独立检查。该静态样例没有验证首选生产应用技术栈，也不是完整无障碍审计。

## 本地决策路由探测

2026-11-03，LM Studio 0.4.26+4 在配备 48 GB 统一内存的 M3 Max 上加载官方 `ggml-org/Kev-0.8B-GGUF` Q8_0 模型。报告的模型大小为 774.77 MiB；加载前估计为 1.06 GiB，置信度低，并非进程内存实测。测试使用一个推理槽位、4,096 token 上下文和 300 秒空闲卸载计时器。首次引擎启动中止，第二次加载在 1.09 秒内成功。

二十四次顺序合成请求（十二个角色任务各重复两次）通过 CodeCrew 实际的 `submitDecision` 客户端调用回环 LM Studio System One 端点。在保持 0.7 置信度阈值时，六次被接受且正确，十八次弃权，没有传输或响应验证失败。含验证的请求耗时中位数为 31 毫秒，95 百分位为 173 毫秒，首次请求为 263 毫秒。所有响应报告零生成输出 token。这一小规模合成探测不能证明编码质量、持续热负荷、图像支持或优于托管 Jev。系统内存查询报告 50% 空闲；受管 shell 无法读取交换与热状态。

本地路由仍为可选项，保存的编码配置未选择本地端点。明确的实现、规划和审查目标复用已保存的 worker 模型，无需顾问选模型；职责含糊或按任务选技能时仍使用有界顾问路径。这是持久配置路由，并非基于学习或基准的模型排名。本次原始合成测量保留在 `/tmp/codecrew-local-router-results.json`。
